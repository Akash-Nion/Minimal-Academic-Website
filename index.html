Projects

Diabetes Risk Prediction

Compared Logistic Regression, Random Forest, and a TensorFlow/Keras neural network for early diabetes risk classification from patient medical attributes (glucose, BMI, blood pressure, age), using standardized feature scaling and ANOVA F-test feature selection.

Car Price Prediction

Built a regression pipeline (Linear, Ridge, Random Forest, Gradient Boosting) to predict car prices from vehicle specs on the UCI Automobile dataset, including a full data-cleaning pipeline and a fixed target-leakage bug — a pandas dataframe-aliasing issue — found in an earlier version of the analysis.

CV R² ≈ 0.92 (Linear Regression)
Python scikit-learn Pandas Regression Gradient Boosting

Laptop Price Prediction

Cleaned a messy real-world laptop listings dataset (mislabeled columns, inconsistent brand casing, corrupted numeric fields) and compared four regression models with 5-fold cross-validation, showing tree-based models handle the non-linear spec-to-price relationship far better than linear ones.

CV R² ≈ 0.75 (Random Forest)
